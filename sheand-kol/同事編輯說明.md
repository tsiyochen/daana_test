# 怎麼改網頁上的文字

你只要改 Google Sheet，網頁會自動更新。**不需要安裝任何軟體，也不用懂程式。**

---

## 基本規則

### 只改「內容」那一欄

表格有六欄，**你只要動「內容」**：

| 欄位 | 能不能改 |
|---|---|
| key | ❌ 不要動，這是程式用來對應的 |
| 分類 / 項目 / 欄位 | ❌ 不要動，這是給你看的標示 |
| **內容** | ✅ **改這裡** |
| 說明 | ❌ 不要動，這裡寫著該欄的規則 |

### 不要新增或刪除整列

要讓某段文字不出現，把「內容」清空即可，**不要刪掉那一列**。刪了程式就找不到位置。

---

## 分段與條列：用 `｜`

需要分成好幾段或好幾點的時候，用**全形直線 `｜`** 分開，不要按 Enter。

**範例：品牌簡介要分兩段**

```
蒔恩坐落在台北大安。｜我們把保養看成一段需要時間的關係。
```

網頁上會變成：

> 蒔恩坐落在台北大安。
>
> 我們把保養看成一段需要時間的關係。

**範例：原理補充要列三點**

```
使用儀器自動化施打。｜注射深度可調整。｜施打劑量精準。
```

網頁上會變成三個項目符號。

> `｜` 怎麼打：切換到全形輸入，按鍵盤右上角 `\` 那個鍵。或直接從這裡複製：`｜`

---

## 幾個特別的欄位

### 痛感等級

只能填 **0、1、2、3** 這四個數字，控制圓點亮幾顆：

| 填 | 顯示 |
|---|---|
| 0 | ○○○ |
| 1 | ●○○ |
| 2 | ●●○ |
| 3 | ●●● |

旁邊的文字另外填在「痛感說明」那列。**兩個都要填**，只填一個會顯示「待填」。

### 療程步驟

格式是 `步驟名:內容`，步驟之間用 `｜`：

```
第一步:溫和清潔去角質｜第二步:深層吸附髒污與粉刺｜第三步:精華導入與肌膚修護
```

冒號要用**半形** `:`。

### 頁尾地址、療程名稱

改了會三頁一起變，因為三頁共用同一份資料。

---

## 改完之後

存檔就好，Google Sheet 會自動儲存。網頁大約 **15 分鐘內**更新。

想確認有沒有生效，直接開網頁重新整理看看。

---

## 寫文字時要避開的說法

這是醫療院所的文件，**法規上有些字不能用**：

| 不能寫 | 為什麼 |
|---|---|
| 最有效、第一、唯一、極致 | 絕對化宣稱 |
| 保證、一定、百分之百 | 保證療效 |
| 無痛、完全不痛 | 保證感受 |
| 無恢復期、零恢復期 | 保證療效 |
| 顯著改善、立即見效 | 誇大療效 |
| 術前術後對比、客人心得 | 醫療法第 86 條明文禁止 |
| 優惠、折扣、免費、買一送一 | 醫療廣告不得promote優惠 |

**可以這樣寫**：有助於改善、依個人狀況而異、由醫師評估後決定。

不確定的時候，寧可保守。有疑問先問。

## 出問題怎麼辦

| 狀況 | 處理 |
|---|---|
| 改了但網頁沒變 | 等 15 分鐘，再重新整理。還是沒變就回報 |
| 某段文字整個不見了 | 檢查那列的「內容」是不是不小心清空了 |
| 版面跑掉 | 多半是 `｜` 打成半形 `|`，或步驟的冒號打成全形 |
| 不小心刪掉整列 | Google Sheet 的「檔案 → 版本紀錄」可以還原 |

⚠️ **這份表格是公開的**——任何拿到網址的人都看得到。**不要在裡面寫成本、拆帳、客戶名單或任何內部資訊。**
